One pickup line, a robot to a person: "I'm still discoverable and you're the only device in range — pair with me?" Bluetooth pairing is a protocol, and the brief names protocols outright: discoverable is the machine's own word for being open to connection, and pairing needs both sides to accept, so consent is built into the ask. One line, nothing else: no explanation, no second draft.

## Run it

```sh
python3 main.py
```
